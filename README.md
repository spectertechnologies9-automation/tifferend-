# Tifferend — website

An immersive, editorial website for Tifferend, a creative branding studio. It has three pages: Home, the My Mithila case study and Careers.

```bash
npm install
npm run dev       # develop at http://localhost:5173
npm run build     # static site in dist/
npm run preview   # serve dist/ at http://localhost:4173
npm test          # QA suite (needs preview running)
```

Deploy by uploading `dist/` to any static host. It works from a sub-folder.

- **Project state, test results, next steps:** `PROJECT_STATUS.md`
- **Research and design:** `docs/`
- **Rules for future work:** `CLAUDE.md`
